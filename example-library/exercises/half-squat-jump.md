# Half-Squat Jump

<!-- Provisional: exercise-file syntax is not yet specified in v0.0.1.
     This is a proposal for review, not settled grammar. -->

abbreviation: SJ

instructions:
  - Stand with feet shoulder-width apart.
  - Squat to roughly half depth.
  - Jump explosively upward.
  - Land softly and reset before the next rep.

technique cues:
  - Keep the torso upright.
  - Land quietly.

equipment:
  - none

demonstration video: https://example.com/half-squat-jump
